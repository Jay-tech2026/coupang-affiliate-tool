# 酷澎當日特價聯盟工具

本機網頁工具。它使用獨立瀏覽器搜尋酷澎台灣商城、讀取商品卡片實際顯示的原價／售價／折扣率，篩選指定折扣以上的商品，再透過官方 Deep Link API 產生 `coupa.ng` 短網址並匯出 CSV。它不使用 Gold Box 名單。

## 第一次使用

1. 安裝 Node.js 18 或更新版本。
2. 複製 `.env.example`，將副本命名為 `.env`。
3. 在 `.env` 填入自己的 `COUPANG_ACCESS_KEY` 與 `COUPANG_SECRET_KEY`。
   台灣帳號請保留 `COUPANG_MARKET=TW`。
   工具會自動使用台灣 API Gateway；如官方日後另行指定，可用 `COUPANG_API_HOST` 覆寫。
4. 在此資料夾執行：

   ```powershell
   npm start
   ```

5. 瀏覽器開啟 <http://127.0.0.1:8788>。

## 自行搜尋 60% 以上商品（Chrome 擴充工具）

酷澎商城會封鎖一般伺服器爬取，因此「自行搜尋」由瀏覽器擴充工具完成：

1. Chrome 開啟 `chrome://extensions`，啟用「開發人員模式」。
2. 將 `extension/config.example.js` 複製成 `extension/config.js`，再填入自己的聯盟 API 金鑰。
3. 按「載入未封裝項目」，選擇本專案的 `extension` 資料夾。
4. 點工具列上的「酷澎高折扣聯盟工具」。
5. 設定最低折扣率與搜尋詞，按「自行搜尋」。
6. 勾選商品並按「產生官方短網址」；工具只接受 `coupa.ng` 結果。

搜尋結果預設不勾選。每個商品可直接按「產生短網址」做單品轉換；需要批次處理時，再自行勾選多個商品。

此流程不使用 Gold Box。折扣率直接取自酷澎商城搜尋結果當下顯示的商品卡片。

1.1.0 版起，擴充功能直接呼叫台灣酷澎 API，不再依賴 `127.0.0.1`、Node.js 或背景服務。

不需要執行 `npm install`，本工具只使用 Node.js 內建功能。

## 安全事項

- `.env` 與 `extension/config.js` 已由 `.gitignore` 排除；真實金鑰只保留在自己的電腦，不會提交至 Git。
- 本工具只監聽 `127.0.0.1`，不會公開到區域網路。
- 發布聯盟連結時，請依酷澎規範與所在地法規揭露廣告／聯盟關係。

## 限制與疑難排解

- 搜尋結果、折扣與庫存會隨時間、登入狀態及酷澎頁面變動；發布前仍應點開短網址確認。
- 預設搜尋「特價、折扣、出清、3折」，可在頁面自行更換或增加搜尋詞。
- 如果收到未授權錯誤，請確認金鑰屬於 **Coupang Partners 聯盟行銷 API**，不是賣家 Wing Open API。
- 系統時間必須正確，因為每次 API 呼叫都使用 UTC 時間建立 HMAC-SHA256 簽章。
- 單次批次轉換上限在工具中設為 100 個網址。
